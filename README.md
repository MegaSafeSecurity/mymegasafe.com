# Mega Safe Security Services Sdn Bhd

Static corporate website built with plain HTML, CSS and JavaScript. No build process or framework is required.

## Files

- `index.html` — website structure and all approved copy
- `styles.css` — responsive layout, colour system and smooth interaction styling
- `script.js` — mobile navigation, scroll reveals, organisation cards, media lightbox and WhatsApp quotation action
- `assets/mega-safe/` — logo, director image, company information reference, organisation chart, media images and company profile PDF

## Edit in VS Code

Open this folder in VS Code and preview `index.html` in a modern browser. All asset links are relative, so the full folder must be kept together.

## Publish on GitHub Pages

Create a repository, upload the files in this folder, then enable **Settings → Pages → Deploy from a branch** using the repository root. The website has no installation or build step.

## Quotation form

The form validates the required contact fields then opens WhatsApp with a ready-made quotation message. The Email and Google Form actions use the contact links supplied for Mega Safe.
